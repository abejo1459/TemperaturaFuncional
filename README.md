## INTRUSCCIONES DE USO 
- Seleccionar una fecha entre el 01/01/2024 y 10/01/2024
- Una vez seleccionada la fecha dar enter por cada fecha elegida para que esta quede establecida.
- Al momento de tener las fechas, presionar el botón "Graficar promedios" para obtener una gráfica con todas las ciudades.
- Para conocer la temperatura extrema, hacer click en el botón "Temperaturas Extremas"
- Si como usuario solo desea conocer la temperatura máxima y minima entre ciudades en una fecha especifica, siga los siguientes pasos.
1. seleccione una fecha correcta en la sección "Fecha a consultar" y de enter en el momento que haya escogido. 
2. Presione el botón "Consultar extremos"
Una vez hecho esto, el programa mostrará la temperatura máxima y minima junto con su respectiva ciudad.

## Getting Started

Welcome to the VS Code Java world. Here is a guideline to help you get started to write Java code in Visual Studio Code.

## Folder Structure

The workspace contains two folders by default, where:

- `src`: the folder to maintain sources
- `lib`: the folder to maintain dependencies

Meanwhile, the compiled output files will be generated in the `bin` folder by default.

> If you want to customize the folder structure, open `.vscode/settings.json` and update the related settings there.

## Dependency Management

The `JAVA PROJECTS` view allows you to manage your dependencies. More details can be found [here](https://github.com/microsoft/vscode-java-dependency#manage-dependencies).
